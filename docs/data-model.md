# 本地输出与飞书数据结构

## 本地输出

每条笔记会生成独立目录，通常包含：

```text
raw_video.json
note_metadata.json
note.md
transcript_zh-CN.txt
core_summary.txt
ingest_report.json
assets/cover_original.webp
assets/subtitle_*.srt
```

同步飞书后，还会保存记录创建结果和最终读取结果，便于核对字段是否完整。

默认输出目录：

```text
~/beef-xhs-library
```

## 视频表

默认包含：

- 视频标题、作者、视频封面、视频链接。
- 视频时长、发布时间、简介、核心总结、文字内容。
- 点赞量、评论量、收藏量。

默认不保存或上传完整视频文件，只保留用户可以打开的分享链接。

## 作者表

默认包含：

- 博主名称、小红书用户 ID、小红书号、主页链接。
- 头像、简介、主页背景图。
- 粉丝量、获赞和收藏量、最近更新时间。

作者优先按小红书用户 ID 识别，其次使用小红书号，最后才使用博主名称。视频表中的作者字段会关联到作者表记录。

## 记录匹配

- 视频优先根据完整分享链接或笔记 ID 匹配。
- 不会只因为标题相同就更新已有记录。
- 已有作者记录会被复用，并在能够取得新资料时补充缺失字段。
